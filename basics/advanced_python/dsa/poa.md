# Simple Python DSA Plan (Iterative Approach)

## The 7-Day Micro-Cycle
Apply this exact timeline to every topic below.

*   **Day 1: Watch (15 mins)** -> Open VisuAlgo. Watch the structure animate. Understand the flow.
*   **Day 2: Code (30 mins)** -> Write a simple Python script (< 20 lines) implementing it.
*   **Days 3–6: Gap** -> Close the file. Do not look at it. Let your mind process it.
*   **Day 7: Refine (20 mins)** -> Open the file. Fix bugs with fresh eyes. Add one optimization comment.

---

## The Learning Path

### Phase 1: Linear Basics
*   **Topic 1: The Stack** (LIFO pattern) -> *VisuAlgo: Stacks*
*   **Topic 2: The Queue** (FIFO pattern) -> *VisuAlgo: Queues*
*   **Topic 3: Linked Lists** (Pointer connections) -> *VisuAlgo: Linked List*

### Phase 2: Searching & Sorting
*   **Topic 4: Binary Search** (Fast finding) -> *VisuAlgo: Sorting (Search module)*
*   **Topic 5: Bubble & Insertion Sort** (Basic sorting) -> *VisuAlgo: Sorting*
*   **Topic 6: Merge Sort** (Divide and conquer logic) -> *VisuAlgo: Sorting*

### Phase 3: Fast Lookups & Trees
*   **Topic 7: Hash Tables** (Key-value mapping) -> *VisuAlgo: Hash Table*
*   **Topic 8: Binary Search Tree (BST)** (Hierarchical storage) -> *VisuAlgo: BST*

### Phase 4: Networks (Crucial for EE)
*   **Topic 9: Graphs** (Matrix vs Adjacency lists) -> *VisuAlgo: Graph DS*
*   **Topic 10: BFS & DFS** (Network traversals) -> *VisuAlgo: Graph Traversal*
*   **Topic 11: Dijkstra's Algorithm** (Shortest path routing) -> *VisuAlgo: SS Shortest Path*
